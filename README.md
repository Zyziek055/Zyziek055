## 🖥️ My HomeLab

I run a home server hosting multiple services in Proxmox LXCs and VMs, including **Nextcloud** for cloud storage, **Immich** as a Google Photos alternative, **Kiwix**, and many more.

### Hardware
- **Lenovo ThinkCentre M720q** – i3-8100T, 24GB RAM – main brain
- **Raspberry Pi 5** – 4GB RAM, PoE+ HAT, NVMe adapter – network infrastructure
- **TP-Link SG1005P** – network switch
